# Seller Scraper API v3

Türk e-ticaret sitelerinden satıcı bilgisi çeken API. Browserless.io kullanır.

## Endpoints

- `GET /` - API bilgisi
- `GET /health` - Sağlık kontrolü
- `GET /api/scrape?url=` - Tek URL scrape
- `POST /api/scrape-multiple` - Çoklu URL scrape

## Desteklenen Siteler

- Trendyol
- Hepsiburada
- N11
